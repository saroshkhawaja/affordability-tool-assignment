### Q1. What is a row?

The raw data set consists of individual indicator values for each country or territory for each year. This long-form data is then filtered and transformed to country level data in the cleaning script, resulting in a final dataset of 191 rows and 12 columns. So each row should be used to represent one country or one country's separate report, but an extra check of the country codes is still required to ensure that all records are distinct. Confidence: High regarding desired structure, but not verified as yet for uniqueness.

### Q2. What is the result (and the units)?

The data set contains a number of economic indicators; namely: GNI per capita, PPP (current international dollars per person); price-level ratio (dimensionless); inflation (annual percentage). It also provides an affordability cluster group, which is a k-means clustering of some data. This group is a derived categorical label, and is not a World Bank indicator, but it is not a measure of tuition fees, accommodation costs or students' household budgets. The indicator units should be confirmed using World Bank metadata. Confidence: high for the units documented and subject to metadata verification and medium for the interpretation of the derived classification.

### Q3. How long is the time period?

It is important to note that data were provided for the latest point available, not as a comparison to a single year: The acquisition script is configured with mrnev=1; which means that the most recent non-empty observation for each country and indicator is returned as the latest-available point. This means that GNI per capita and inflation figures can be from different years for the same country, making it difficult to compare in time. To determine the degree of this variation, the actual earliest and latest reporting year(s) and the number of observations in each year must be known. Confidence: high for the expected behavior of the API, lower for the cross-country temporal comparability of the dataset until the reporting years are confirmed.

### Q4. Who is missing?

The original country-level CSV had 201 records and the cleaned CSV had 191 records, so there are 10 records that appear in the original but are omitted from the cleaned CSV. The 10 countries or territories not included were Andorra, Bermuda, Eritrea, Faroe Islands, Greenland, Marshall Islands, Puerto Rico US, Somalia Fed Rep, Turkmenistan and Turks and Caicos Islands. The newer cleaning run was reported separately and removed 26 rows due to having missing information on essential indicators. The numbers represent different processing stages and should NOT sum. It remains to be seen if the same ten countries or territories were excluded in the latest API download. Confidence: High for the previous CSV comparison, the latest API download hasn't been verified.

### Q5. What is meant by sampling frame?

The target population are countries and territories where prospective international students may want to study abroad, while the available data are countries with economic indicators that are relevant to the topic of the WBI in the World Bank World Development Indicators (WDI) database. The dataset is not a random sample since regional aggregates and missing essential indicators have been eliminated during the cleaning process. This can result in bias, because countries that are not covered by WDI may be removed from the final sample, and thus all possible study countries may not be represented equally. Moreover, the method used to collect WDI data can vary between different indicators, and can be either based on national surveys or on statistical modelling, therefore the specific data collection method must be verified using metadata from the World Bank. Confidence: high with regards to API coverage and selection rules, but low with regards to the statistical methods for the time being until the documentation is checked.
